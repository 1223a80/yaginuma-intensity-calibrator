# 滑动变祖器

一个「八系强度校准器」网页小玩具。拖动滑杆，人物会在 31 个等级间连续变化，从「八嘎」一路进化到「八神」。

## 现在能做什么

- 六个状态：八嘎、牢八、金毛、八木沼、金发天才、八神
- 滑杆范围为 −15 到 +15，并使用连续视频帧平滑呈现中间状态
- 支持鼠标、触摸和键盘，适配桌面和手机浏览器
- 不包含投票、社区均值或时间线功能

## 本地运行

```bash
npm install
npm run dev
```

运行测试与生产构建：

```bash
npm test -- --run
npm run build
```
